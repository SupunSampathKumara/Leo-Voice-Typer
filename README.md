LEO Voice Typer v2.0 - README

1. Information (About the Software)
LEO Voice Typer is a free voice-typing application designed to help users easily type in Sinhala, Tamil, and English using their voice. This software was proudly developed by the Leo Club of University of Colombo, Faculty of Arts, under the "Able Hands" project. Version 2.0 is specially optimized for visually impaired students, allowing full control through simple keyboard shortcuts and screen readers.

2. Installation Guideline
Follow these simple steps to install the software on your computer:

Step 1: Double-click the setup file to open the installer.

Step 2: Read the License Agreement, select "I accept the agreement," and click Next.

Step 3: Read the Information screen and click Next.

Step 4: Choose where to install the software (the default C:\Program Files\LEO Voice Typer is recommended) and click Next.

Step 5: Tick the box "Create a desktop shortcut" if you want an icon on your desktop, then click Next.

Step 6: Click Install and wait a few seconds for the files to extract.

Step 7: Once finished, tick "Launch LEO Voice Typer" and click Finish to open the application.

3. How to Use

Ensure your computer has a working microphone and an active internet connection.

Open the LEO Voice Typer application.

Select your preferred language from the dropdown menu.

Open the document where you want to type (e.g., MS Word, Notepad, or a Web Browser).

Press the global shortcut Ctrl + Shift + Space (or click the microphone button) to start listening.

Speak clearly into your microphone, and the text will be typed automatically.

Press Ctrl + Shift + Space again to stop typing.

4. Keyboard Shortcuts

Global Shortcuts (Works anywhere, in Word, Notepad, Web Browsers):

Ctrl + Shift + Space : Toggle Voice Typing On / Off

Application Shortcuts (Works when the LEO Voice Typer window is active):

Alt + L : Focus Language Dropdown

Alt + M : Focus Microphone Button

Ctrl + 1 : Select English

Ctrl + 2 : Select Sinhala

Ctrl + 3 : Select Tamil

Ctrl + Q : Quit Application

Navigation for Visually Impaired:

Tab : Move to the next element

Shift + Tab : Move to the previous element

Space / Enter : Activate the focused button

Up / Down Arrows : Change language when dropdown is focused
